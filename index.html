03

How I work

Step 01

Read the design

I start in Photoshop — understanding layer structure, font choices, colour intent, and how the design should behave when personalised.

Step 02

Extract assets

Clipart, backgrounds, and elements are prepared and exported. Fonts are identified and loaded. Foil and colour variants are mapped out.

Step 03

Configure in JS

The Mediaclip theme is built using platform-specific JavaScript — selector logic, variant conditions, font loading, and collage creation all written from scratch within Mediaclip's own engine

Step 04

Ship to production

The product is previewed, tested across variants, then pushed live — ready for customers to personalise and order in real time.
